1. Ringkasan Eksekutif

Sistem Tsunami Indonesia adalah portal pemantauan kebencanaan geospasial dan edukasi mitigasi publik yang dirancang untuk menyajikan data gempa bumi terkini serta rekam jejak kejadian tsunami historis di wilayah Indonesia dan Samudera Pasifik. Platform ini menggabungkan layanan API resmi nasional (BMKG InaTEWS) dan internasional (NOAA NCEI Global Hazard Service) melalui arsitektur berorientasi performa tinggi, bebas ketergantungan pihak ketiga (zero-dependency), dan tangguh diakses dalam kondisi darurat jaringan pesisir.

2. Integrasi Layanan API (Application Programming Interface)

Platform mengintegrasikan tiga ekosistem API utama untuk menyediakan pemantauan langsung (live monitoring), basis data historis, serta visualisasi peta dasar:

1. BMKG InaTEWS Open Data Autogempa Metode: GET (JSON)
https://data.bmkg.go.id/DataMKG/TEWS/autogempa.json

Fungsi: Mengambil informasi gempa bumi mutakhir Indonesia secara otomatis setiap ada pembaruan sensor BMKG. Parameter mencakup Magnitudo (M), Kedalaman (km), Wilayah Episentrum, Koordinat Lintang/Bujur, Tanggal, Jam WIB, dan Keterangan Status Potensi Tsunami.

2. NOAA NCEI Tsunami Hazard Service REST API Metode: GET (JSON)
https://www.ngdc.noaa.gov/hazel/hazard-service/api/v1/tsunamis/events?country=INDONESIA&minYear=1900

Fungsi: Mengambil arsip saintifik kejadian tsunami laut dari tahun 1900 hingga sekarang. Mengembalikan ketinggian hempasan maksimum (max water height), kode penyebab (tektonik, erupsi vulkanik, longsoran bawah laut), koordinat asal, dan korban jiwa terverifikasi.

3. Esri ArcGIS REST Map Tile Service Format: Slippy Map Tiles (XYZ)
https://server.arcgisonline.com/ArcGIS/rest/services/World_Topo_Map/MapServer/tile/{z}/{y}/{x}

Fungsi: Menyediakan basemap peta topografi alami dan batimetri kedalaman laut dunia dengan kontras tinggi, bebas watermark komersial, serta layer pelengkap seperti World Street Map dan World Imagery (citra satelit).

4. Reverse Proxy Lokal & Serverless Edge (/api/bmkg & /api/noaa) Arsitektur Internal
/api/bmkg  |  /api/noaa

Fungsi: Menangani pembatasan CORS (Cross-Origin Resource Sharing) browser, menginjeksi header keamanan, serta menerapkan mekanisme cache in-memory (s-maxage=60, stale-while-revalidate=120) untuk menjaga stabilitas kueri dan menghemat kuota transmisi data.

3. Standar Evaluasi Potensi Tsunami & Estimasi Tinggi Gelombang

Berdasarkan Standar Operasional Prosedur (SOP) BMKG InaTEWS, sistem menjalankan fungsi analisis evaluateBmkgTsunamiPotential(gempa) pada modul js/api.js untuk mengevaluasi data mentah menjadi indikator keselamatan yang dapat dipahami masyarakat umum:

Tingkat Peringatan Ambang Parameter Gempa Estimasi Gelombang Status Potensi Instruksi Tindakan

(Bahaya Sedang)		 Berpotensi Tsunami (Tingkat Sedang) Evakuasi warga dari sempadan pantai dan muara sungai.

4. Spesifikasi Framework, Library, dan Arsitektur Perangkat Lunak

Arsitektur perangkat lunak dirancang dengan prinsip Zero Heavy Frameworks demi menjamin efisiensi performa eksekusi, interoperabilitas tinggi, serta pemeliharaan kode yang terstruktur:

A. Frontend Engine: Vanilla JavaScript (Native ES6+)

  • Pendekatan: Bebas dari framework frontend berat (seperti React, Vue, atau Angular). Murni menggunakan standar ECMAScript 6+ native browser.
  • Keunggulan:
    • Nol Overhead Virtual DOM: Manipulasi DOM dilakukan secara presisi pada elemen yang dibutuhkan tanpa proses rekonsiliasi berlebih.
    • Waktu Muat Instan: Ukuran transfer file JavaScript total hanya ± 35 KB, memungkinkan situs termuat dalam hitungan milidetik bahkan pada koneksi seluler 3G/darurat.
    • Bebas Proses Build: Kode berjalan langsung tanpa membutuhkan kompilasi bundler seperti Webpack, Vite, atau Rollup.

B. CSS & Antarmuka Pengguna: Tailwind CSS + Custom CSS

  • Tailwind CSS (via CDN): Digunakan untuk utility classes perancangan tata letak fleksibel (flexbox, CSS grid, breakpoints responsif mobile hingga desktop, dan utility spacing).
  • Custom Stylesheet (css/style.css): Mengatur identitas visual Deep Oceanic Dark Navy:
    • Palet Warna Utama: Navy gelap kontras (#0b1329, #0f172a, #1e293b) dengan aksen Cyan/Sky Blue (#38bdf8) dan Emergency Red (#dc2626).
    • Komponen Kustom: Kartu transparan backdrop blur (ele-card), tombol aksi tegas (ele-btn-primary, ele-btn-secondary), serta styling popup Leaflet gelap (ele-leaflet-popup).
    • Standar Tipografi: Menggunakan font sans-serif modern Inter dari Google Fonts dengan hierarki kontras yang mudah dibaca.

C. Engine Pemetaan Geospasial: Leaflet.js (v1.9.4)

  • Library Peta: Leaflet.js versi 1.9.4 (diakses melalui jaringan CDN unpkg resmi).
  • Fitur Geospasial yang Diimplementasikan:
    • Penyajian koordinat kartografis dan konversi derajat geografis (Lat/Lng).
    • Render layer interaktif: L.circleMarker untuk arsip tsunami historis dan L.divIcon berdenyut (pulsing marker) untuk episentrum gempa BMKG live.
    • Manajemen layer kontrol untuk perpindahan basemap (Topografi, Wilayah, Satelit) dan legenda klasifikasi tinggi gelombang laut.
    • Fitur navigasi kamera (flyTo) otomatis saat pengguna meninjau titik gempa atau memilih kartu peristiwa tsunami.

D. Backend Runtime: Native Node.js & Vercel Serverless Ready

  • Runtime Lokal (local-server.js): Dibangun menggunakan modul bawaan native Node.js tanpa dependensi npm pihak ketiga (dependencies: {} di package.json).
    • Modul http & https: Mengelola web server dan proxy API luar.
    • Modul fs & path: Mengalirkan file statis dengan penentuan tipe MIME yang tepat serta mendukung Clean URLs (misal: /peta otomatis memuat /peta.html).
  • Kompatibilitas Serverless (api/bmkg.js & api/noaa.js): Berformat fungsi serverless standar Vercel Node.js Serverless Function yang siap dideploy ke cloud secara global tanpa konfigurasi server fisik.
Keamanan & Stabilitas Bebas Dependensi Eksternal (Zero Dependencies)
Dengan 0 dependensi eksternal pada package.json, sistem kebal terhadap risiko kerentanan keamanan rantai pasok (supply-chain vulnerabilities), tidak membutuhkan instalasi ribet (npm install), dan menjamin keberlanjutan kode dalam jangka panjang tanpa risiko pustaka kadaluwarsa (*deprecated*).
